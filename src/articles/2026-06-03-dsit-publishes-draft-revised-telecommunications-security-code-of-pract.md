1. The Department for Science, Innovation and Technology (DSIT) published a Draft Revised Telecommunications Security Code of Practice on 3 June 2026.
2. The draft was presented to Parliament under sections 105E and 105F of the Communications Act 2003.
3. The Code gives guidance on how public telecoms providers can comply with the Telecommunications (Security) Act 2021 and the Electronic Communications (Security Measures) Regulations 2022.

## Background

The Code of Practice sits within the UK's telecoms-specific security framework set out in the Telecommunications (Security) Act 2021. That Act introduced security duties for public telecoms providers and enforcement powers for Ofcom.

The framework also includes the Electronic Communications (Security Measures) Regulations 2022. Together, the Act and the Regulations set the duties and requirements that the Code helps providers meet.

The original Telecommunications Security Code of Practice was first published on 1 December 2022. It complements the wider UK cyber resilience landscape, including the NCSC's Cyber Assessment Framework and the forthcoming Cyber Security and Resilience Bill.

## Developments

DSIT published the Draft Revised Telecommunications Security Code of Practice on 3 June 2026. It was presented to Parliament under sections 105E and 105F of the Communications Act 2003.

The revised Code provides detailed guidance for large and medium-sized public telecoms providers on how to comply with the Telecommunications (Security) Act 2021 and the Electronic Communications (Security Measures) Regulations 2022. The revision refines language, incorporates changes to address new threats and technological advancements, and reinforces the expectation that providers take a risk-based approach to security.

The document carries the ISBN 978-1-5286-6420-2. The print-ready PDF runs to 178 pages (1.39 MB), and the web accessible PDF runs to 176 pages (1.31 MB). An explanatory memorandum of 5 pages (188 KB) and a change log ODS file (54.1 KB) accompany the publication.

The government consulted on the proposed updates in late 2025. It published the consultation response in June 2026.

## What to Watch

The Code of Practice will continue to be reviewed and updated periodically. Future updates will be informed by advice from the NCSC, evidence from public telecoms providers, and security reports from Ofcom. Parliament will be given the opportunity to scrutinise any revised version.
