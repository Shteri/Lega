## Key Takeaways

1. HM Treasury published the Financial Transaction Control Framework on 30 October 2024, setting out the government's approach to managing financial transactions such as issuing loans and investing in financial assets.
2. The framework requires new, large-scale financial transactions to be delivered through designated expert public financial institutions.
3. The framework requires transparent reporting on the value and performance of financial assets held by government.
4. Costs must be recognised in departmental budgets where investments are expected to be loss-making from the outset.
5. On 3 June 2026, HM Treasury added a supplementary paper on risk budgeting for public financial institutions, covering the implementation of economic capital-based controls.
6. A Financial Transaction Checklist and an accessible HTML version of the framework were added in early 2025.

## Background

The Financial Transaction Control Framework forms part of HM Treasury's management of the public sector balance sheet. It sits alongside the government's fiscal rules and public financial institution governance.

The framework was referenced in relation to the Autumn Budget 2024 and the Spring Statement 2025. It reflects the government's approach to how public money is deployed in loan and equity instruments.

The framework defines financial transactions as issuing loans or investing in financial assets such as equity. It sets out when government will use these transactions and the controls that apply to their use.

## Developments

HM Treasury first published the Financial Transaction Control Framework on 30 October 2024. The main document is a 60-page PDF (1.06 MB) with ISBN 978-1-917151-96-2.

The framework makes several commitments. New, large-scale financial transactions must be delivered through designated expert public financial institutions. The government must report transparently on the value and performance of the financial assets it holds. Costs must be recognised in departmental budgets where investments are expected to be loss-making from the outset. The framework also introduces new risk-based controls.

The document has been updated several times. On 26 March 2025, HM Treasury updated the framework and added the Financial Transaction Checklist March 2025, a 47.6 KB ODT file. On 1 April 2025, an accessible HTML version of the framework was added.

On 28 May 2026, a Risk Budgeting for Public Financial Institutions paper was initially added, then removed. On 3 June 2026, HM Treasury added the final version, titled Risk Budgeting for Public Financial Institutions: Implementing economic capital-based controls. This paper is 52 pages (1010 KB) and supplements the framework's risk-based controls.

The framework affects HM Treasury, government departments, public financial institutions delivering large-scale financial transactions, and public sector balance sheet managers.

## What to Watch

The framework continues to be updated, with the most recent change made on 3 June 2026. Affected entities should monitor HM Treasury for further updates to the framework and its supplementary materials.
